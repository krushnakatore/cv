# Krushna Katore — Portfolio

Personal portfolio built with Next.js (pages router), React 19 and Tailwind CSS v4. Live at https://krushna-katore-portfolio.vercel.app.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Content (experience, projects, skills, education) lives in `src/data/portfolioData.ts`.
